## شروع سریع

1. **دیدن طراحی همین الان:** فایل `preview/index.html` را در مرورگر باز کنید (یا از پیش‌نمایش زنده همین سند).
2. **ساخت اپ:** پوشه `AtiranHamrahAndroid` را در Android Studio باز کنید و ▶️ را بزنید:
   ```bash
   cd AtiranHamrahAndroid && ./gradlew assembleDebug
   ```
3. **امن‌سازی سرور:** دو فایل `server-fixed/` را جایگزین نسخه‌های فعلی در IIS کنید.
