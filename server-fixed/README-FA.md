# نسخه اصلاح‌شده فایل‌های سرور (AtiranLocalServices)

این پوشه شامل فایل‌های اصلاح‌شده سرویس WCF موجود شماست. برای اعمال، فقط کافی است این دو فایل را
به‌جای نسخه‌های فعلی در پوشه سرویس (IIS) کپی کنید:

- `Web.config`
- `LocalServices.svc`

## خلاصه تغییرات

| مورد | نسخه اصلی | نسخه اصلاح‌شده |
|---|---|---|
| رمز عبور پایگاه داده در فایل | `"user id=atiranhamrah;password=ahmad100"` | حذف شد (Integrated Security + راهنمای رمزنگاری) |
| مرور دایرکتوری (directoryBrowse) | روشن | بسته |
| نمایش جزئیات خطا به کلاینت (includeExceptionDetailInFaults) | روشن | خاموش |
| متادیتای عمومی (httpGetEnabled) | روشن | خاموش |
| Debug در فایل .svc | true | false |
| سقف حجم پیام WCF | بدون سقف | ۲ مگابایت |
| هدر X-Powered-By | ارسال می‌شد | حذف شد |
| maxItemsInObjectGraph | ۲٬۱۴۷٬۴۸۳٬۶۴۷ (بدون سقف عملی) | ۱٬۰۰۰٬۰۰۰ |

## رمزنگاری رشته اتصال (پیشنهاد جدی)

پس از جایگزینی فایل، روی سرور اجرا کنید:

```
cd %WINDIR%\Microsoft.NET\Framework64\v4.0.30319
aspnet_regiis -pe "connectionStrings" -app "/نام-اپلیکیشن-در-IIS"
```

با این کار رشته اتصال در سطح DPAPI ویندوز رمز می‌شود و در فایل متنی قابل خواندن نیست.

## نکته درباره HTTPS

سرویس فعلی روی HTTP اجرا می‌شود. برای استفاده اپلیکیشن اندروید در بستر اینترنت عمومی حتماً
یک گواهی SSL روی IIS فعال کنید؛ در شبکه محلی (LAN) اپ اندروید به‌صورت پیش‌فرض اجازه اتصال
HTTP دارد (فایل `network_security_config.xml` پروژه اندروید).

## گام بعدی پیشنهادی

سرویس WCF و .NET Framework 4.5.2 فرسوده شده‌اند (پایان پشتیبانی مایکروسافت). مسیر ارتقای
